# Learning path

The React app includes six home-row exercises. Complete each exercise at its target speed and within its mistake allowance to unlock the next. Levels 1–6 require 15, 16, 18, 20, 22 and 30 WPM, respectively, and allow 5, 5, 4, 4, 3 and 3 mistakes. Each exercise uses only keys introduced up to that point. Completed exercises can be replayed, and Practice offers a choice of unlocked exercises. The timer starts with the first typed character, pauses with the lesson, and records elapsed time. Paused time does not count. WPM uses correct characters divided into five-character words over the actual active typing time; accuracy counts correct attempts out of all typed attempts, and the combo counts consecutive correct attempts. The keyboard highlights the next expected key. Learners must correct mistakes before advancing; each incorrect character counts once and correction does not add a mistake. Rugo warns when the allowance is nearly used. Exceeding the allowance ends the attempt immediately; completing the exercise below its speed target also fails. Both failures show a reason and a retry, with no XP or unlock. Completing the exercise automatically shows the results. Pasting or dropping text into an exercise is disabled. New learners see an introduction to F and J before their first lesson. Only passed exercises count toward progress. Results award one star for passing, two for at least 90% accuracy, or three for at least 98%; results show stars for the current attempt and the best star count is saved for each lesson. Results point out the most frequently missed expected key when there were mistakes. Speed charts use actual samples from the current attempt and display an empty state if there are too few samples. A passed lesson offers the next lesson when one is available; retry starts a fresh attempt. The first clear of a level earns 20 XP; replays still count as practice but do not earn that first-clear reward again.

Progress, XP, best WPM, activity dates and daily goal totals are saved in the browser's local storage under `rugo-progress`. They are specific to the browser and origin, not synced to an account. If browser storage is unavailable, a notice appears on the main screen. Daily goals reset at the next local calendar day. The league page is informational until an online leaderboard is implemented; Unit 2 remains unavailable.

Opening an exercise from the path or Practice shows a brief full-screen preparation screen; learners can start immediately. Retrying from results begins a fresh attempt directly. The lesson uses a focused layout; navigation and progress return when the learner goes back to the path.

Rugo is a reusable SVG character with independently animated head, eyes, eyebrows, mouth, body, arms, legs and tail. The learning-path mascot cycles through reusable idle, happy, curious, thinking, surprised, proud and celebration expression templates when activated. He uses a side-facing walk cycle during preparation and reacts to lesson results, with distinct eyes, brows and mouth shapes for celebration, surprise, thought and encouragement. Motion respects reduced-motion settings. On the learning path Rugo stays visible while scrolling; smaller screens use a compact corner placement. The earlier Rive and illustrated experiments are retained as source material and are not used in the app.

On compact screens, the learning path, progress panels, keyboard guide and lesson results adapt to the available width. The fixed mascot uses a smaller footprint on phones.

Lesson and results action bars stay visible at the bottom of the viewport while content scrolls.

Sound effects use Howler.js and locally generated short cues for starting a lesson, typing, mistakes, combo milestones and results. Five, ten, twenty, thirty, fifty, seventy-five and one hundred correct keys trigger a short milestone; larger milestones have a distinct cue. Rugo reacts to long combos and offers encouragement after a mistake. The Sound control is available on the learning path, during lessons and on results; the setting persists on the device. Sounds start only after interaction and can be muted.



Run `npm run test:lesson` to check the lesson scoring, correction, stars, mistake summaries and daily rollover rules.
